# Pre-submission review, 2026-09-07

This folder is the audit trail for one round of external adversarial review. It is
included in the release so that a later reader can check the response against the
review rather than taking the response on trust.

| File | What it is |
|---|---|
| `REVIEW-FINDINGS-PRESUBMIT.md` | The external review as received, unedited. |
| `CITATIONS-UNVERIFIED.md` | The external bibliography audit as received, unedited. |
| `RESPONSE-TO-REVIEW.md` | What was changed, what was not, and where this response disagrees with the review. |

Two conventions are worth stating. Findings that were **not** acted on are listed with
the reason, not omitted. And where verification contradicted the review, the response
says so and gives the command to re-check it, rather than quietly following the
reviewer.
